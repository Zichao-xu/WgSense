# 代理面板一比一复刻 · 功能对照清单

参照：[liandu2024/AnGe-ClashBoard](https://github.com/liandu2024/AnGe-ClashBoard) v1.91（zashboard 分支）
原则：**功能一比一，视觉用苹果语言**。原版源码只当规格读，不运行网页版。

已定决策（2026-09-27）：
- 依赖 AnGe 服务端的功能 → 原生 App 自己 SSH 连 op（OpenWrt，`10.10.1.1:9990`，已确认运行 **OpenClash**）实现
- 纯网页功能砍掉：访问密码/登录页、后端中转控制器、背景图服务端存储、移动端布局与滑动切页、下拉刷新、更新面板、从 URL 自动导入设置
- 保留多后端管理
- 位置：替换 WgSense 现有代理页；AnGe 的一级导航（概览/代理/连接/日志/规则/设置）= 代理页顶部标签；AnGe 侧栏的速度图/统计/后端切换 = 代理页顶部信息条

### 1.13 原生版的设计取舍（不改变功能）

- **视觉**：苹果语言（分组区块、圆形/方形徽章、系统控件），不追像素
- **性能**：连接/流量走 Mihomo WebSocket 推送，不再每秒整包拉取；只刷新可见区域；组下载速度从连接推送增量计算
- **图标**：组图标支持 Mihomo 配置里的 `icon` URL，下载后本地缓存
- **SSH**：复用现有 `ssh -p9990 root@10.10.1.1` 密钥；所有写操作先备份远端文件
