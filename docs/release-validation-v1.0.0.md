# WgSense v1.0.0 验证范围

## 已验证

- Go 全量测试与竞态检测、`go vet` 通过。
- macOS Release App 构建通过，App 与 Widget 版本均为 1.0.0，构建号 21。
- 内置 daemon、安装和卸载脚本存在且可执行；App 代码签名完整性检查通过。
- 本地 DMG 已制作并只读挂载检查，安装包内 App 版本为 1.0.0。
- 隔离测试覆盖服务首次安装、升级、并发锁、失败回滚、卸载重装、VPN 冲突检测与网络恢复代码路径。

## 尚未实机验收

- 首次安装的管理员密码提示次数、取消后重试及真实 launchd 安装。
- Mac 冷重启、App 重开、VPN 反复开关时的免密码行为。
- 睡眠唤醒、断网、网络切换后的实际握手、流量、DNS 与路由恢复。

当前构建采用临时签名，尚未由 Apple 公证。常驻后台服务的本机 HTTP API 仅适合用户已接受该安全取舍的个人环境。
