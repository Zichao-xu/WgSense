# WgSense v1.0.11

设置页新增「区域底色」，可分别调整左侧卡片、底部工具栏和右侧内容面板的颜色。

- 点击各区域右侧的色块选择颜色，立即生效并保存；每个区域都有独立的「恢复默认」。
- 右侧内容面板覆盖普通页面、代理列表，以及测速页的线路条、仪表底板和展开的抽屉。
- 自定义底色下，面板文字随底色明暗调整，保留选中与悬停的区分。
- 原有「窗口材质」中的背景模式、背景浓度保持独立；未选自定义颜色时沿用原来的外观。
- 新增设置文案提供与现有界面一致的 10 种语言。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。

本版仅更新界面，无需升级或重启后台服务。仍采用临时签名，尚无 Apple Developer ID 签名与公证。

验证范围：本机 Release 构建；颜色逻辑 36 项检查、16 张原生面板渲染；既有 HUD 模型与运动检查通过。设置页已实际打开。按用户要求停止追加交互和逐页测试，不宣称完整流程或全部页面已验收。
