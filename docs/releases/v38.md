# WgSense v38

## 路由追踪

- 鼠标滚轮缩放地图（原来是转地球），触控板双指滑动仍是转地球；Mos 这类平滑滚动工具也按滚轮处理，停手后带惯性滑停。
- 地球展平成平面时不再在极地附近撕开破口：平面改为以视野中心为准的方位等距投影，并推迟到放大后段才展平，过渡看不出来。
- 拖动改为与 MapLibre 地球模式一致：北始终朝上，横向按纬度补偿速度；松手惯性不会越过极点乱跳。
- 最大缩放提到一屏约 0.3°，放大后计算精度修正，不再抖动。
- 重点地区细分到市 / 区，放大后逐级显示边界与地名：广东 21 个地级市、珠三角区县、东京区市町村、加州与纽约州的县（纽约市标五个区名）。
- 广东、东京、纽约、旧金山湾区、洛杉矶五块换成精细陆地与海岸线，放大后珠江口、香港、东京湾、哈德逊河与东河不再是大块三角形。
- 航线由抛物线改为闪电（实验性）：沿行政边界从上一站劈到下一站，并向全国闪出分叉；当前这一跳附近最亮，之前各段只留主干。
- 修复：放大到省级以上时航线让地图掉到约 10 帧（原因是抛物线虚线在画面外也照画），现在各缩放下都在 100 帧上下。

数据来源：Natural Earth（国界、省界）；阿里云 DataV（广东与港澳市区边界）；国土数値情報 N03（东京及周边）；美国人口普查局 1:50 万县界与 TIGER 水面（加州、纽约周边）。生成脚本 `platforms/macos/tools/trace-regionprep.py`。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。本版未改动后台服务，直接替换 App 即可。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 本机 Release 构建与安装包检查；README 检查通过。
- 深圳、东京、纽约、湾区、加州逐处截图核对边界、地名与海岸线；国内目标实测追踪核对闪电航线。
- 压测剧本各场景地图帧率 97–120（改动前放大场景 7–29）；待机与自转 CPU 约 2%。
- 闪电航线的最终观感尚未定稿，后续版本会继续调整。
