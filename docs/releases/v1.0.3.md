# WgSense v1.0.3

菜单栏合并实时网速、日期与时间（原独立工具 NetTimeBar 的功能）。本版不改变 WireGuard、路由、DNS 或守护策略的实现。

## 更新内容

- 菜单栏图标在盾牌状态之后依次显示实时网速、日期徽章和时间，四者共用一个菜单栏位置。
- 网速上传在上、下载在下，固定宽度、固定数字槽位，速率变化时菜单栏不左右跳动；可选字节/秒或比特/秒，统一以紧凑的 `m`/`g` 显示，刷新频率 0.1–2 秒。
- 网速只统计 Wi‑Fi、以太网、USB 与雷雳网卡等物理出口，不重复计算 VPN 隧道（utun）、AirDrop 与虚拟接口流量。
- 日期徽章采用泰国星期色，可开关毛玻璃并调整颜色浓度；时间支持 12/24 小时制与应用内时区，不修改系统时区。
- 左键打开原控制面板；右键打开组件菜单，可分别显示或隐藏网速、日期与时间。
- 已使用 NetTimeBar 的用户，首次启动时自动沿用其时区、单位、刷新频率等偏好；升级后可退出 NetTimeBar，避免菜单栏重复显示。
- 菜单栏入口从 SwiftUI MenuBarExtra 改为原生 NSStatusItem：MenuBarExtra 的图标位只渲染单张图像与文字，无法容纳双行网速与彩色徽章。

## 安装与更新

官方安装包支持 **Apple Silicon（M 系列）Mac，macOS 26 或更新**。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」。`SHA256SUMS.txt` 提供下载文件的校验值。

更新前请在 App 内点击「停止」并退出 App，再替换旧版。新版本启动后会检查后台版本，必要时升级并重启后台服务。

本版仍采用临时签名，尚无 Apple Developer ID 签名与公证。首次打开方式与完整入门见 [使用指南](https://github.com/Zichao-xu/WgSense#开始使用)。

## 验证与已知边界

- 本机以预览版实际运行：菜单栏四个组件显示正确，网速读数与独立版 NetTimeBar 一致，左键面板内容与旧版一致，NetTimeBar 偏好导入生效；切换前后隧道状态不变。
- 发布流水线执行 Go 检查与竞争检测、HUD 模型与运动回归、品牌与文档检查、Release 构建、包内版本/架构及严格签名验证，通过后才生成附件。
- 菜单栏组件菜单目前只有简体中文，尚未接入 App 的多语言切换。
- 本机后台控制接口尚无调用者认证，沿用可信个人 Mac 的使用边界。
