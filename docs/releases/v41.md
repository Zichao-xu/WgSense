# WgSense v41

## 出站拦截

- 新增「放行域名」。本机代理软件要直连境外的自建节点时，把域名或 IP 填进设置 → 出站拦截，不用关掉拦截。
- 域名每分钟重新解析一次，节点 IP 变了会自动跟上。名单里每一项都显示当前解析到的地址。
- 解析失败或解析结果是 fake-ip 时，沿用上次的真实地址，DNS 抖动不会断掉正在用的节点。
- 放行只在「拦截境外直连」下生效。隧道锁定和国内模式不放行。
- 无效的域名不会保存，也不会写进防火墙规则。旧版 App 保存设置时不会清空放行名单。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。本版改动了后台服务。更新后请在 App 内先点「停止」断开 VPN，再点「守护」，App 会升级并重启后台服务。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 本机 Release 构建与安装包检查；README 检查通过；后台服务 Go 测试全部通过，新增放行名单的规则、解析回退、模式隔离和持久化测试。
- 手工把节点 IP 加进实际 pf 规则，实测只放行该地址，代理节点恢复，其他境外地址仍被拦截。
- 未实测：发布前没有用新版后台服务跑完整的放行名单流程。
