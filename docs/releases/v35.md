# WgSense v35

版本号从这一版起改为单个递增数字（上一版是 v2.0.0）。

## 测速更快开始，等待看得见

- 从点击开始到码表转动，实测由约 19 秒缩短到约 9.5 秒：
  - 解析测速源跳转时拿到响应头就返回。原先百度 CDN 无视「只取 1 字节」直接推整个文件，每次白等 8 秒。
  - 上行测速源改到上行开始前再挑，下行选完源立即开测。
  - 打开测速页时预先连好到执行端的 SSH，点开始时省去握手。
- 开测前（连接执行端、测空载延迟、试测测速源）读数下方显示当前步骤、本步用时和跳动的点，尚未开跑的通道上有扫动的暗亮带，不再像卡住。

## 布局

- 调节面板（开发预览版 ⌥⌘T）新增「版面」组：侧栏顶部留白、页面最大宽度、测速仪表缩放上限。
- 页面默认铺满窗口宽度，不再限制在 820pt 居中。
- 测速仪表放大到上限后高度与字号不变，多出的宽度横向展开（两翼外伸、右侧面板贴右、管线拉长）。
- 链路舞台改用与其他卡片相同的半透明面板底，Liquid Glass 下不再是一块不透明的深色。

## 修复

- 概览页打开时顶部标题被裁掉、滚不上去：数据晚到使内容变高时，滚动容器没有跟着变高。
- 区域底色变成纯灰、盖住玻璃：选色时透明度被丢弃（只存 RGB），甚至只点开色块不选也会写入不透明色。现在保存透明度、色块可调透明度；旧版存下的颜色按 72% 透明度读回。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。

本版仅更新界面与测速脚本，无需升级或重启后台服务。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：本机 Release 构建与安装包检查；区域底色 39 项、HUD 模型 61 项与动效 34 项、README 与配图、档位检查通过。概览页滚动高度修复前后各启动 3 次对比；测速提速为在执行端直接运行脚本分段计时；测速仪表横向展开与等待画面为离线渲染核对。未在 App 内完整跑一次测速。
