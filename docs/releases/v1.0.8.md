# WgSense v1.0.8

新增「测速台」：在路由器、本机或任意 SSH 主机上发起测速，看清宽带、隧道和局域网的真实速度，以及卡在哪一段。

## 更新内容

- **测速台**（侧栏新增「测速」磁贴，点开为完整页面）：
  - **执行端 × 路径 × 目标**：执行端可选本机、代理后端里配了 SSH 的路由器、手动添加的 SSH 主机；目标可选公网或名册里的另一台机器（iperf3）。WG peer 从路由器的 WireGuard 配置自动发现。
  - **宽带直连**：在路由器上绑定物理网口、用真实 DNS 逐跳解析，绕开隧道、代理与 fake-ip，测的是宽带本身。
  - **两端之间**：iperf3 对测；对端能 SSH 登录时临时起服务端，测完即停；对端缺 iperf3 时临时部署静态版，测完删除。
  - **结果**：上下行稳态（预热后的中位数）、峰值、波动；空载与负载延迟；网口协商速率与利用率；瓶颈判断——平顶贴着网口速率为 LINK，平顶但没到为 UPSTREAM，并给出余量。
  - **过程可见**：测量链路（执行端 → 网口 → 并发连接 → 出口 → 源）、候选源的试跑结果（入选 / 淘汰）、断线重连都按真实事件呈现，每秒 4 次采样。
  - **历史**：每次结果按场景保存，可回看。
- **公网测速源不写死**：源列表是远程 JSON（可放 secret gist，在「测速源」里填地址），App 启动时拉取并缓存，拉不到用缓存。每个源记健康分，连续失败 3 次自动跳过；某个方向没有可用源时只跳过这个方向，另一方向照常出结果。格式见 `docs/speedlab/sources.example.json`。

## 安装与更新

官方安装包支持 **Apple Silicon（M 系列）Mac，macOS 26 或更新**。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」。`SHA256SUMS.txt` 提供下载文件的校验值。

本版没有改动后台服务；从 v1.0.7 更新只需替换 App。从更早版本更新时，请在 App 内先点「停止」断开 VPN，再点「守护」，App 会升级并重启后台服务。

本版仍采用临时签名，尚无 Apple Developer ID 签名与公证。首次打开方式与完整入门见 [使用指南](https://github.com/Zichao-xu/WgSense#开始使用)。

## 验证与已知边界

- 在 OpenWrt 路由器（PPPoE 千兆宽带）上实测宽带直连：下行稳定约 500 Mbps（套餐上限，判为 UPSTREAM），上行约 970 Mbps（贴着网口，判为 LINK）。
- 实测 iperf3：路由器 ↔ NAS 局域网约 4.2 / 2.2 Gbps；本机经 WG 隧道到路由器。
- 实测单方向无可用源时跳过该方向、两方向都无源时报错；测速源失效（某高校测速站临时不可达）时自动淘汰。
- 测速台界面用离线逐帧渲染（`tests/speedlab/render.sh`）按真实窗口宽度检查过各阶段画面。
- 公网测速会在测速期间占满宽带；大陆没有稳定公开的测速节点目录，源列表需要随节点变化手动更新。
- 本机在 WG 全局隧道下无法绑定物理网卡直连（缺网卡专属路由），宽带测速请以路由器为执行端。
- 自动部署 iperf3 的路径未在缺 iperf3 的设备上实测（家中设备均自带）。
