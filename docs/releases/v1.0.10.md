# WgSense v1.0.10

本版整合测速台改进与实时排版优化。拖动侧栏时，文字按当前宽度换行，磁贴按当前列数重新排列。

## 更新内容

- 移除侧栏和测速页的弹性截图覆盖：拖动期间直接更新真实界面，无需松手或停顿后补换行。
- 磁贴采用单一布局容器，跨行、跨列时保留视图身份；固定高度磁贴直接计算几何，减少反复测量。
- 测速页及测法章节按可见区域加载；普通页面的原生滚动容器合并重复测量，并在内容变化时更新高度。
- 公共斜切底板改用原生图层，随尺寸变化更新路径，减少整块位图重绘。保留测速 HUD 的固定设计坐标与实时缩放。
- 整合此前未发布的测速台改进：完整可调测法、单项恢复、每次结果保存测法、可调采样间隔，以及实时读数与统计轨迹更新。

## 安装与更新

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。

本版没有改动 Go 后台服务；从 v1.0.8 更新无需重新部署后台服务。测速执行脚本随 App 更新。

仍采用临时签名，尚无 Apple Developer ID 签名与公证。打开方式见 [使用指南](https://github.com/Zichao-xu/WgSense#开始使用)。

## 验证范围与边界

- 本机 Release 构建完成；布局几何回归通过，原生窗口已打开运行。用户完成实际体验后要求停止额外测试并发布。
- 布局图片比较在 352 点宽度存在像素差异，未继续扩展排查，不列为全量视觉验收通过。
- 本版以实时真实排版为准；不承诺所有页面、所有数据规模稳定 120fps。
- 公网测速会占用带宽；本次界面整合没有重新启动公网测速或远端维护操作。
