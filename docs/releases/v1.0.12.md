# WgSense v1.0.12

界面的间距、字号、圆角改为统一档位，不再各处写死。

- 原先 900 多处写死的数值（间距十几种取值、字号 29 种）收拢为 8 档间距、11 档字号、2 档圆角，数值集中在 `WgTokens.json`。
- 本版启用新的档位数值，各页面的留白、字号和圆角随之统一调整。
- 开发预览版新增「布局调节」面板（菜单「调试」，⌥⌘T）：拖动滑块整个界面实时变化，可显示参考线标出每块内边距的档位，「保存到工程」写回 `WgTokens.json`。正式版不含该面板。
- 新增档位检查：之后再写死可归档的数字，CI 与发版构建会直接失败。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。

本版仅更新界面，无需升级或重启后台服务。仍采用临时签名，尚无 Apple Developer ID 签名与公证。

验证范围：本机 Debug 与 Release 构建通过；档位检查正反两路实测；默认档位下 15 个页面迁移前后截图对照无溢出或截断；调节面板实时生效与保存已实际使用。本版发布的档位数值未另做逐页截图。
