# WgSense v1.0.1

本版更新 macOS 界面与链路观测，包含 v1.0.0 之后累积的代理面板、滚动性能和服务安装修复。

## 更新内容

- 新增交互式「链路舞台」：真实收发均速、握手刻度、自愈记录和最近 30 秒流量轨迹；支持指针感应、收发聚焦及采样固定/解除。
- 使用连续缓动、错峰入场与有限回弹；活动期间按显示器刷新率更新，空闲暂停，支持系统「减少动态效果」。
- 修复告警色面、流量斜面及扫描动画遮挡自愈记录的问题，覆盖深浅色、宽窄布局和最大流量档位。
- 更新主窗口、菜单栏与代理面板，加入策略组、节点、提供商和域名规则视图，以及流量曲线与原生滚动容器。
- 修复旧临时后台文件已被删除时无法继续迁移、安装流程访问受保护下载目录失败、安装失败后重复请求管理员密码等问题；受信任网络继续由守护策略保持 VPN 断开。
- 修复流量计数回退后速度残留，并减少重复巡检日志。

## 验证与已知边界

- HUD 模型与运动函数共 95 项回归通过。218 张原生渲染画面已核查；8 张极限遮挡画面的 96 个记录标记全部可见，4 对记录区像素一致，已加入回归检查。
- 独立原生预览中已点验聚焦、复位、轨迹固定/解除和主题、布局切换。
- 在 M1 Pro 内置 120Hz 屏幕上，连续事件绘制提交平均 120.00 次/秒；连续指针压力测试为 116.64 次/秒，最长提交间隔 62.68ms。**尚不能保证全场景稳定 120fps**；上述数据不是 GPU 实际呈现帧率，也不能替代正式 App 整页的长期验收。
- 全量 Go 检查、竞争检测、macOS Release 构建、包内版本与签名检查由本次发布流水线执行；通过后才生成发布附件。
- 真实网络切换、冷重启及升级后的长期稳定性仍需目标环境验收。既有小窗口侧栏挤压问题尚未整体调整。

## 安装

当前官方安装包面向 Apple Silicon Mac，要求 macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」。`SHA256SUMS.txt` 提供下载文件的校验值。

本版仍使用临时签名，尚未完成 Apple 公证。常驻后台的本机 HTTP API 仍未提供调用者认证，沿用现有个人环境使用边界。

发布操作不会自动安装或切换正在使用的 App，也不会自动操作现有隧道、DNS 或路由。
