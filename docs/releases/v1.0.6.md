# WgSense v1.0.6

省电版本：日常只运行核心网络业务，图表与实时推送只在主窗口打开时运行。外出用电池时后台开销大幅下降。

## 更新内容

- **后台服务不再反复调用系统命令**：此前每次查询网卡状态都要启动 `ifconfig`、`networksetup`，网络检测每 3 秒一次、巡检和界面拉取状态时还会重复查询，空闲时约每 20 秒启动 75 个子进程。现在：
  - 网卡元数据按地址与启停状态缓存，状态不变时直接复用，最长 60 秒刷新一次。
  - 默认路由直接读内核路由表，不再调用 `route`。
  - 网络变化改由系统通知触发（网卡启停、地址增删、路由变化），另有 15 秒兜底检查；切网反应更快，平时不再定时唤醒。
- **视觉数据只在呼出时运行**：代理概览的速度/内存曲线、连接推送与规则刷新只在主窗口真正可见时运行；窗口被遮挡、最小化、关闭超过 3 秒即停止，回到前台自动恢复。菜单栏小面板不会启动这些数据流。
- **修复连接推送泄漏**：此前打开过一次代理概览后，mihomo 连接推送会一直在后台运行。
- 隧道收发、受信任网络判断、断线自愈、出站拦截逻辑均未改变；菜单栏网速与时间照常刷新。

## 安装与更新

官方安装包支持 **Apple Silicon（M 系列）Mac，macOS 26 或更新**。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」。`SHA256SUMS.txt` 提供下载文件的校验值。

本版改动了后台服务。更新后请在 App 内先点「停止」断开 VPN，再点「守护」，App 会升级并重启后台服务。

本版仍采用临时签名，尚无 Apple Developer ID 签名与公证。首次打开方式与完整入门见 [使用指南](https://github.com/Zichao-xu/WgSense#开始使用)。

## 验证与已知边界

- 在真实环境以隔离副本实测新后台服务：30 秒内零次启动子进程，累计 CPU 时间约 0.1 秒（旧版同等条件约 20 秒启动 75 个子进程，空闲 CPU 约 9%）。
- 原生默认路由读取与 `route -n get default` 结果一致（自动化测试对照）；网络通知过滤规则有单元测试。
- 发布流水线执行 Go 检查与竞争检测、HUD 模型与运动回归、品牌与文档检查、Release 构建、包内版本/架构及严格签名验证，通过后才生成附件。
- 「连接历史」统计依赖连接推送，现在只在主窗口打开期间累计。
- 网卡链路速率变化（不伴随地址变化时）最多延迟 60 秒反映到界面。
