# WgSense v1.0.4

新增整机「出站拦截」：在 WireGuard 没有保护流量的时候，主动挡住 AI 服务或全部境外站点的直连。拦截作用于整台电脑（pf 防火墙 + `/etc/hosts`），与 WG 链路无关。

## 更新内容

- **自动拦截**：离开受信任网络时生效，只拦从物理网卡直连出去的流量，走 WG 隧道的流量不受影响。WG 断开、重连空窗、假连接期间漏出的直连会被挡住；回到受信任网络自动解除。
- **国内模式**：手动强制开关，任何网络、包括走 WG 隧道的流量一律拦截。
- **两档范围**：
  - 仅 AI：内置 Claude、ChatGPT、Gemini、Grok、Perplexity、Cursor 等域名名单（可在设置中编辑），另加 Anthropic 自有 IP 段。共享 CDN 的服务只做域名级拦截，避免误伤其他站点。
  - 全部境外：只放行国内 IP（约 6000 段，随包内置）、局域网与 WG 服务器。检测到其他系统 VPN 时自动让路。
- 被拦连接立即被拒绝，不会卡到超时；生效瞬间不打断已建立的国内长连接。
- 规则 fail-closed：后台服务意外退出时保持拦截。可在 App 内关闭开关、卸载服务，或执行 `sudo /usr/local/libexec/wgsense-daemon --firewall-clear` 紧急解除。
- 设置位于「设置 → 出站拦截」，默认全部关闭，单独保存，不随守护配置同步覆盖。
- 规则挂在系统 pf.conf 自带的 `com.apple/*` 锚点下，不修改 `/etc/pf.conf`；pf 启用采用引用令牌，不影响系统其他使用者。

## 安装与更新

官方安装包支持 **Apple Silicon（M 系列）Mac，macOS 26 或更新**。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」。`SHA256SUMS.txt` 提供下载文件的校验值。

更新前请在 App 内点击「停止」并退出 App，再替换旧版。本版改动了后台服务，新版本启动后会升级并重启后台服务。

本版仍采用临时签名，尚无 Apple Developer ID 签名与公证。首次打开方式与完整入门见 [使用指南](https://github.com/Zichao-xu/WgSense#开始使用)。

## 验证与已知边界

- 以 root 在真实环境（非受信任网络、WG 全局隧道已连接）实测：模拟绕过隧道的直连，AI 目标与境外 IP 在 15ms 内被拒；国内直连与走隧道访问不受影响；隧道断开时 AI 域名解析为 `0.0.0.0`、恢复后自动移除；结束后 pf 锚点与 hosts 完整还原。
- 发布流水线执行 Go 检查与竞争检测、HUD 模型与运动回归、品牌与文档检查、Release 构建、包内版本/架构及严格签名验证，通过后才生成附件。
- hosts 不支持通配符，子域名需在名单中单独列出；绕过系统解析的程序（自带 DoH 等）只能靠 IP 级规则拦截。
- 受信任网络下使用国内模式「全部境外」档时，经网关 fake-ip 代理的境外站点会被一并拦截（符合国内模式预期）。
- 出站拦截设置界面目前只有简体中文。
