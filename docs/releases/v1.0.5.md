# WgSense v1.0.5

出站拦截简化为一条全局规则，并补上 IPv6 与开机空窗两处漏口。不再区分在家与否、不再维护 AI 域名名单。

## 更新内容

- **一条规则，任何网络都生效**：物理网卡只放行国内 IP（含 IPv6）、局域网、网关 fake-ip 段（`198.18.0.0/15`）和 WG 服务器，其余直连立即拒绝。
  - WG 连着：流量走隧道，不经物理网卡，不受影响。
  - WG 断开或重连空窗：境外直连（含 AI 服务）一律拒绝。
  - 在家：境外流量解析为 fake-ip 交给网关代理，照常；拿到真实境外 IP 想直连的会被拒绝。
- **IPv6 直出已封住**：WG 隧道只承载 IPv4，此前公网 IPv6 会从网卡绕出。现在 IPv6 与 IPv4 用同一份国内段放行，其余拒绝，程序会立即回退到 IPv4。
- **国内模式**：同一规则作用于所有接口（含 WG 隧道），且不放行网关 fake-ip，真正只上国内。
- **开机无空窗**：后台服务启动时先装拦截规则，再启动隧道与其他服务。
- 设置页「出站拦截」精简为两个开关：「拦截境外直连」「国内模式」；v1.0.4 已打开的开关原样保留。状态行只显示正在使用的网卡。
- 移除 v1.0.4 的受信任网络判断、「仅 AI / 全部境外」档位、AI 域名名单与 `/etc/hosts` 域名拦截；升级后自动清除 v1.0.4 写入 `/etc/hosts` 的条目。

## 安装与更新

官方安装包支持 **Apple Silicon（M 系列）Mac，macOS 26 或更新**。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」。`SHA256SUMS.txt` 提供下载文件的校验值。

本版改动了后台服务。更新后请在 App 内先点「停止」断开 VPN，再点「守护」，App 会升级并重启后台服务。

本版仍采用临时签名，尚无 Apple Developer ID 签名与公证。首次打开方式与完整入门见 [使用指南](https://github.com/Zichao-xu/WgSense#开始使用)。

## 验证与已知边界

- 以 root 在真实环境（非家庭网络、WG 全局隧道已连接）实测：绕过隧道直连境外 IPv4/IPv6 在 15ms 内被拒；国内 IPv4/IPv6 正常；走隧道访问不受影响；关闭开关立即放行；v1.0.4 的 hosts 遗留被清除。
- 发布流水线执行 Go 检查与竞争检测、HUD 模型与运动回归、品牌与文档检查、Release 构建、包内版本/架构及严格签名验证，通过后才生成附件。
- WG 断开时所有境外站点都不可达，这是设计目标。若所连网络的 DNS 服务器在境外，WG 断开时域名解析也会失败。
- 在家经网关 fake-ip 代理的场景、以及国内模式，本版未做实机联网验证（规则语法与单元测试已覆盖）。
- 出站拦截设置界面目前只有简体中文。
