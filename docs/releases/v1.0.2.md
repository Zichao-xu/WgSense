# WgSense v1.0.2

新的品牌图标与更完整的使用指南。本版延续交互式链路 HUD，不改变 WireGuard、路由、DNS 或守护策略的实现。

## 更新内容

- 全新至上主义风格图标：交错斜面贯穿左右边缘，保留中央切口与朱红短线，覆盖全部 10 个 macOS 图标尺寸。
- 主窗口与关于页适配浅色、深色和跟随系统：浅底黑 X、深底白 X，红线保持同色；移除关于页图标的额外阴影。
- Dock、Finder 和通知继续采用深色平面图标，不增加系统光泽效果。
- 重写 GitHub 首页：加入原生 HUD 配图与动态演示、安装与首次使用步骤、权限与隐私说明、更新卸载和常见问题。
- 新增图标母版一致性、12 种原生品牌渲染，以及文档配图与链接检查，纳入自动构建和发布流程。

## 安装与更新

官方安装包支持 **Apple Silicon（M 系列）Mac，macOS 26 或更新**。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」。`SHA256SUMS.txt` 提供下载文件的校验值。

首次运行需授权安装后台服务；日常控制使用已安装服务。更新前请在 App 内点击「停止」并退出 App，再替换旧版。新版本启动后会检查后台版本，必要时升级并重启后台服务。

本版仍采用临时签名，尚无 Apple Developer ID 签名与公证。首次打开方式与完整入门见 [使用指南](https://github.com/Zichao-xu/WgSense#开始使用)。

## 验证与已知边界

- 本机已安装并实际启动 1.0.2（23），点验浅色、深色与跟随系统外观；App 与 Widget 版本一致。
- 全部 10 个 AppIcon 槽位与双主题资源进行母版检查；从实际 App 资源包原生渲染两种外观 × 六种尺寸，共 12 项检查。
- 发布流水线执行 Go 检查与竞争检测、95 项 HUD 模型与运动回归、品牌与文档检查、Release 构建、包内版本/架构及严格签名验证，通过后才生成附件。
- 动态演示使用合成数据。120Hz 是活动动画请求上限，仍不保证所有场景稳定 120fps；真实冷重启、网络切换与长期连接恢复的完整验收仍待完成。
- 本机后台控制接口尚无调用者认证，沿用可信个人 Mac 的使用边界。小窗口侧栏过宽时仍可能挤压正文。
