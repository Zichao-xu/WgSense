# WgSense v36

## 路由追踪

侧栏新增「路由追踪」页：输入域名或 IP，逐跳追踪路由，并把途经的城市画成航线。

- 世界地图在地球和平面之间连续过渡：缩小是可以转动的地球，放大逐渐展平成平面地图，放到省级可以看到中、日、美三国的省界。
- 镜头会跟着新出现的站点飞过去，全部追踪完后拉远看全程。
- 操作：
  - 拖动、双指滑动：转动地球或平移地图，松手有惯性。
  - 捏合、滚轮、⌘ + 双指滑动：以指针处为中心缩放，捏合松手也有惯性。
  - 双指按下拖动：挪动视图。
  - 双击放大，⌥ 双击缩小。
  - 方向键、`+` / `-`：转动和缩放。
  - `Esc` 或 AUTO：回到跟随航线。
- Fake-IP 适配：代理用 fake-ip 接管了目标域名时，本机只能追到代理网关。这时页面会向代理后端查询真实去向，读出规则与节点，并把「代理段」接着画出来。七步判定逐条显示在右下角，与跳点表放在一起，可以收起。
- 定位只把公网跳点的地址发给 ip-api.com，内网与隧道地址不出本机。
- 地球待机时缓慢自转，转一分钟或窗口失去焦点后慢慢停下，停下后不再绘制。地图用 Metal 直接在显卡上绘制，待机自转时约占 15–20% CPU，停下后约 2–5%。

## 侧栏可收起

侧栏底部的 `‹` 可以把磁贴收成一列图标，`›` 展开。收起时磁贴不再渲染。

## 出站拦截：放行诊断探测

拦截境外直连时，默认放行 ICMP 回显（traceroute / ping），路由追踪能看到真实路径；其他协议照拦。隧道锁定与国内模式下不放行。设置 →「出站拦截」新增「放行诊断探测」开关。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。

本版改动了后台服务。更新后请在 App 内先点「停止」断开 VPN，再点「守护」，App 会升级并重启后台服务；升级前「放行诊断探测」开关显示为不可用。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 后台服务的 Go 测试全部通过，其中包括新增的「仅拦截模式放行探测」测试；pf 规则语法已用 pfctl 检查。
- 本机 Release 构建与安装包检查；README 配图与档位检查通过。
- 路由追踪页用压测剧本测过帧率：自转、惯性、飞行约 120 帧，拖动与缩放约 100–105 帧（脚本送输入的上限）。地球、展平过渡、平面三种形态均截图核对。
- 实际追踪测过国内多跳目标；境外目标在拦截模式下放行探测的效果，要升级后台服务后才能验证，本版发布前未验证。
