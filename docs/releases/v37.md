# WgSense v37

## 侧栏收放

- 拖动侧栏分隔线时宽度无级变化，磁贴随宽度连续收缩成图标；松手后吸附到最近的整列宽度：收起、一列、两列、三列、四列、五列。
- 吸附接住松手时的手速：轻甩可以跳到下一档，落位时带一点回弹。
- 分隔线正中的 `‹` / `›` 收起、展开侧栏，过程和拖动一样逐帧排版，磁贴不跳。
- 修复：侧栏拖到约 120 点宽时，图标列整体右移并被分隔线切掉。原因是底部品牌栏出现时把整列撑宽。
- 底部品牌栏按宽度降级：放不下名字就只留按钮，再窄只留标志和设置，不会竖排或撑出侧栏。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `WgSense-macOS.dmg`，将 App 拖入「应用程序」替换旧版。本版未改动后台服务，直接替换 App 即可。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 本机 Release 构建与安装包检查；README、配图、档位、品牌与外观检查通过。
- 侧栏在 119、120、121 点和 130–300 点逐宽度截图核对；拖动扫宽与待机 CPU 与改动前持平（待机约 1%）。
- 松手吸附与回弹的手感由人工拖动确认。
